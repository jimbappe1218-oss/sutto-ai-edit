# スッとカット（無音カット）

話していない部分を見つけて詰めます。映像はフレーム単位、音声はサンプル単位で同じ位置を切るので、音ズレしません。つなぎ目には 8 ミリ秒のフェードが入り、プチッという音が出ません。

スクリプト: このスキルのフォルダの `scripts/muon_cut.py`（以下 `SKILL_DIR` は、この SKILL.md があるフォルダ）。

## 手順

1. **先に調べる（書き出さない）**
   ```bash
   python3 "SKILL_DIR/scripts/muon_cut.py" "入力.mp4" --dry-run
   ```
   最後の行 `RESULT_JSON: {...}` を読む。`removed_seconds`（何秒減るか）、`cuts`（何か所）、`warnings` を利用者に伝える。
2. **減りすぎ・減らなすぎなら設定を変えて、もう一度調べる**（下の「頼まれ方 → 設定」）。
3. **書き出す**（`--dry-run` を外す）。出力は `元の名前_無音カット.mp4`。元のファイルは変更しない。
4. `duration_output` が `duration_after` と合っていることを確かめ、何秒 → 何秒になったかを報告する。

## 頼まれ方 → 設定

| 頼まれ方 | 設定 |
|---|---|
| ふつうに無音カット | 既定（`--min-silence 0.5 --keep 0.12`） |
| テンポを速く・ジェットカット・YouTuber っぽく | `--min-silence 0.3 --keep 0.06` |
| 自然な間は残して・落ち着いた感じで | `--min-silence 0.9 --keep 0.2` |
| 長い沈黙だけ消して | `--min-silence 2.0 --keep 0.3` |
| 語尾が切れる・食い気味 | `--keep` を 0.05 ずつ大きくする |
| 息つぎ・小さい物音が残る | `--threshold` を上げる（例 `-40` → `-35`） |
| 小さい声まで切れてしまう | `--threshold` を下げる（例 `-45`） |

`--keep` の 2 倍は `--min-silence` より小さくすること（そうでないとエラーになる）。

## 結果の見方

- `threshold_db`: 声と無言の境目。`noise_floor_db`（静かなときの音量）と `speech_level_db`（声の音量）の間に自動で置かれる。
- `warnings` に「声と無言の音量差が小さい」と出たら、BGM 入りの素材か、雑音が大きい素材。`--threshold` を手で指定する（`speech_level_db` より 15〜20 小さい値から試す）。
- `元の名前_無音カット.mp4.cuts.json` に、残した区間（元の動画での秒）がすべて入る。

## 注意

- **BGM が入っている素材には向きません**（音がずっと鳴っているため、無言を見つけられない）。BGM は無音カットのあとに入れる（`sutto-bgm`）。
- テロップを入れるなら、**無音カット → 文字起こし → テロップ** の順にする。先に文字起こしをすると、カットで時刻がずれる。
- 映像は再圧縮される（H.264、画質 `--quality 18`。数字が小さいほど高画質）。
- **やり直すと、同じ名前の前回の出力は上書きされる。** 前の版を残したいときは `--out "別の名前.mp4"`（フォルダを渡すと、その中に既定の名前で作る）。利用者に「前の版は残しますか」と確かめてから進める。
- 音声だけのファイル（.wav / .mp3 / .m4a）も処理できる。出力は .wav。
